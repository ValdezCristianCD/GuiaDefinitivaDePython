# Condicionales en Python

Los condicionales permiten que un programa tome decisiones en base a ciertas condiciones. En Python, se usan principalmente `if`, `elif` y `else`.

---

# Tipos de condicionales

- **if**: Ejecuta un bloque de código si se cumple la condición.
- **if-else**: Ejecuta un bloque si se cumple la condición, otro si no.
- **if-elif-else**: Permite evaluar varias condiciones.

---

# Sintaxis básica

```python
if condicion:
    instruccion
else:
    instruccion_alternativa
```

---

# Ejemplos prácticos

1. Verificar edad:

```python
edad = 18
if edad >= 18:
    print("Es mayor de edad")
else:
    print("Es menor de edad")
```

2. Temperatura:

```python
temperatura = 30
if temperatura > 30:
    print("Hace calor")
else:
    print("Está agradable")
```

---

# Resumen visual

- `if` evalúa una condición.
- `else` es la opción alternativa.
- `elif` permite agregar más condiciones.
